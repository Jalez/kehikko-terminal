- **A real terminal in a container.** Your own login shell, with full-screen programs, colours, ctrl-C, arrow keys and `vim` all working.
- **One shell per project.** Terminal keeps a shell for each project the canvas has been on and shows the one for the project you are in, so switching back finds your shell as you left it.
- **Nothing in the way.** No picker and no chrome while the shell is alive: the container is the terminal.
