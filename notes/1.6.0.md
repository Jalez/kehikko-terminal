- **The footer says what the shell is doing.** Under the terminal you see whether a command is running and which one, or that the shell is idle, along with the folder it is in and which shell it is. A terminal folded down to its top and bottom rows still shows it.
- **Why a shell ended is said in the footer.** When the shell exits, the footer says why. New shell stays at the top.
- **The renamed-folder line moved to the footer.** When the project's folder is renamed under a running shell, the footer says so and has Dismiss beside it, so the line no longer pushes the terminal down.
